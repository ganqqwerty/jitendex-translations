# YSMOKE-V101 — Ручной smoke-тест Yomitan v1.0.1

YSMOKE-V101-1 — Используйте новый чистый профиль Chrome с установленным Yomitan. Не проводите тест в основном профиле: импорт и обновление меняют локальную базу словарей.

YSMOKE-V101-2 — В корне репозитория запустите сервер с двухчасовым ограничением: `./.venv/bin/python scripts/run_with_timeout.py 7200 ./.venv/bin/python -m http.server 8766 --bind 127.0.0.1 --directory work/yomitan-v1.0.1-smoke-server`.

YSMOKE-V101-3 — Импортируйте `work/yomitan-v1.0.1-smoke-server/jp-ru-kolobok-400k-v1.0.0-local-smoke-yomitan.zip`. Убедитесь, что название словаря — `Колобок 400k`, а revision заканчивается на `v1.0.0-local-smoke`.

YSMOKE-V101-4 — Проверьте точные lookup: `食べる` → `食べる`; `たべる` → `食べる`; `食べました` → `食べる`; `ありがとう` → `ありがとう`; `生` показывает чтения из отчёта. Для rendering используйте `悪どい` для xref и ссылок, `明白` для ruby, `ＣＤプレーヤー` для примера, Tatoeba и таблицы, а `掛ける` как самую длинную структурированную статью.

YSMOKE-V101-5 — Найдите `社会情報學` и убедитесь, что redirect подписан `вариант написания`, а не `redirected from`. Для ограничений проверьте `中２` → `только 中２・中二`, `オメガ` → `только Ω` и `アンド` → `только ＡＮＤ`; tooltip во всех трёх случаях — `допустимо только для этих форм и/или чтений`.

YSMOKE-V101-6 — Проверьте сохранённые термины: `悪どい` показывает JMdict, `ＣＤプレーヤー` — Tatoeba, `Ｗｉｎｄｏｗｓ` — Windows/Microsoft, `鱒の介` — `Oncorhynchus tshawytscha`, `ブルーバック` — `BSoD`, `格` — английское `that`, `スベタ` — португальское `espada`. В примере `バカ騒ぎ` должно быть `Мы вчера вечером, выпив, ходили по всему городу и вовсю кутили.` без бывшего `losили`.

YSMOKE-V101-6A — Машинно выбранные ZIP-member, row, reading и ожидаемый фрагмент для каждого случая находятся в `reports/yomitan_localization/run59-v1.0.1-smoke-cases.json`; не подбирайте другие примеры, если этот список доступен.

YSMOKE-V101-7 — Запомните порядок словарей и включённость `Колобок 400k`. Нажмите обновление словарей. Yomitan должен получить `http://127.0.0.1:8766/yomitan.json`, скачать финальный v1.0.1 ZIP и показать revision `2026.08.21.0-jp-ru-kolobok-400k-v1.0.1-tags-ru-v1` без установки Jitendex.

YSMOKE-V101-8 — Убедитесь, что порядок и включённость словаря не изменились. Остановите сервер. В чистом тестовом профиле можно удалить профиль Chrome целиком; основной профиль затрагивать не нужно.

YSMOKE-V101-9 — Скопируйте `reports/yomitan_localization/run59-v1.0.1-smoke-template.json` в `reports/yomitan_localization/run59-v1.0.1-smoke.json`, поставьте `true` только у реально наблюдавшихся пунктов и кратко опишите версии Chrome и Yomitan в `notes`. После этого выполните YRP-CMD-13 с именем наблюдателя.
